日期：2026-09-09。結果：本次發現的問題已修正，原始碼檢查、21 項自動測試、完整建置及下列瀏覽器操作均通過。

## 排查範圍

- 目前所有 React 路由、共用元件、工具函式、樣式、設定、題庫建置腳本、Python 資料轉換腳本與專案文件。

- 95 個部署題庫分片、27,196 筆原始／標準化索引、12,061 張實際引用圖片。
- 專案是純前端靜態網站；目前沒有後端 API、帳號資料庫或跨裝置同步。本次資料邏輯排查涵蓋題庫生成、動態載入、判分與本機進度儲存。

## 主要修正

| 原本問題 | 修正後行為 |
| --- | --- |
| 詳解頁每次 render 重讀儲存物件，造成 effect 反覆觸發 | 穩定快照與相依值，詳解可正常載入、停留、返回 |
| 缺少 ID 時可能錯配第一題；網址重複解碼可能丟錯 | 嚴格識別題目；不以相同年份／題號跨梯次猜題；安全處理 `%` |
| 載入失敗被快取成空題庫、某年度失敗卻繼續出題 | 失敗可重試；年度分片缺失會明確報錯，不悄悄縮小題庫 |
| 離開、重新整理、跨科可能丟失答案與計時 | 依科目／年份保留題序、答案、標記與截止時間；錯題複習也可恢復 |
| 計時依 interval 次數遞減，背景分頁容易失準 | 以實際截止時間計算，返回分頁立即校正；五分鐘提示可持續顯示 |
| 作答量與正確／錯誤統計更新時點不一致 | 統一於交卷更新；選答案和改答案不重複增加每日總量 |
| 複選可接受答案、送分題以單字母精確比較 | 保留來源答案規則，接受資料中指定的任一正確選項；漏答另計 |
| 錯題複習未同步成長、漏答保留數不完整 | 正確移除、錯誤與漏答保留；複習更新每日統計，結果可重載 |
| 複習答錯卻增加熟練階段 | 答錯重設複習間隔，不因失敗次數而被判為精熟 |
| 手動「我已經會了」只改錯題本 | 同步更新清除／熟練紀錄，不虛增作答量或正確率 |
| 大型錯題集合逐題重寫 localStorage | 每次交卷批次更新集合；到期查詢共用一次狀態快照 |
| 儲存空間不足、禁止儲存可能使頁面或交卷中斷 | 安全儲存封裝、當前分頁記憶體保留、明確提示與下載備份 |
| 結果重複保存整份題目與計算結果 | 保存一份題目／答案快照，結果頁重新計算，降低儲存量 |
| 清除進度遺漏動態結果 key，或重新匯入舊資料 | 清理指定使用者的完整進度，阻止該使用者被舊資料重新填回 |
| 錯題／收藏一次渲染全部內容 | 預設 20 題，按需載入更多；圖片佔位符改為正式附圖 |
| 暗色模式、手機對話框、側選單焦點不一致 | 主題選單同步；頁內確認框支援取消、焦點限制與 Esc；改善小螢幕排版 |
| 年份只剩 79 題仍顯示可開始 80 題測驗 | 選科頁直接提示不足並導向調整年份 |
| 未知路由、渲染錯誤沒有可恢復頁面 | 加入找不到頁面、錯誤邊界及返回入口 |

## 圖片與建置

來源中有 726 張副檔名是 PNG、實際格式不同的圖片：616 張 JPEG、110 張 JPEG 2000。實測民國 115 年第一次「放射線診斷原理與技術學」第 40 題，原本六張附圖均顯示載入失敗。

這 726 張已重新封裝為真正的 PNG，逐張驗證「尺寸、色彩模式與解碼後的像素位元組完全相同」。沒有生成、修飾或重畫影像。原始位元組保存在 `.cache/original-image-formats/`，其中 `conversion-report.json` 記錄前後 SHA-256 與像素核對。修正後該題六張附圖均成功解碼。

相鄰的附圖分條也改成連續排列，保留原始順序、縮放比例，避免圖片被條狀空白分隔或過度放大。Python PDF 萃取函式同步修正，避免日後再把 JPEG 2000 位元組直接存成 `.png`。

原先龐大的 `public/uploads` 已完整移至 `.cache/audit-original-uploads/` 保存。建置只同步題庫實際引用的圖片，檢查 PNG 格式並比較內容後更新。開發監看與 Tailwind 掃描也排除大量歷史／圖片產物。

上述驗證完成時，結果尚未 commit、push 或發布；其後依使用者要求，將本次修正納入既有 GitHub main → Cloudflare Pages 發布流程。正式站的發布狀態須另以 Cloudflare 部署結果與線上操作核對。

原始格式備份與舊部署圖片備份位於 `.cache/`，正常建置不依賴這些備份。未來新增來源圖片若格式錯誤，可使用 `scripts/normalize-source-images.py` 修復；它需要支援 JPEG 2000 的 Pillow，日常 npm 建置不需要 Pillow。
